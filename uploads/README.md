# Arateko — Wireframe

Wireframes low-fidelity do **Arateko** (Innovation Intelligence & Strategy, by Arateko Labs).

`index.html` é um wireframe autônomo (abra no navegador) do **MVP — Copilot de sessão** (intensidade
Sprint), aterrado no método: o **Funil de Valor** de 5 fases com os **4 gates humanos**.

## Fluxo (MVP)
`Onboarding → Escopo/4Ms → Charter (GATE 1) → Expandir (opções+critérios) → Ranquear/MCDA (GATE 2) →
Convergir/Funil (GATE 3) → Operar/KPIs (GATE 4) → Decision log`

Legenda: **IA: rascunho** (a IA amplia) · **GATE: aval humano** (o humano decide) · **artefato** (o que
a fase deixa pronto). Princípio: agentes ampliam o volume; humanos decidem os julgamentos de valor.
